# Oluwademilade Fajolu - Portfolio

A static portfolio for graduate and junior backend opportunities, using HTML, CSS and a small JavaScript navigation enhancement. Hosted on the existing Vercel project.

## Preview locally

Serve this directory with any static HTTP server, for example:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173`. There is no install or build step.

## Content

- `index.html`: profile, selected projects, experience, education and contact links.
- `index.css`: responsive styles, keyboard focus and reduced-motion support.
- `index.js`: accessible mobile menu and footer year.
- `assets/Oluwademilade_Fajolu_Backend_CV.pdf`: downloadable CV; replace this when the CV changes.

The attendance project graphic is an architecture illustration, not a product screenshot. Descriptions are based on the owner's CV. The Outspan entry records the current NYSC placement without claiming duties or outcomes that have not yet been established. Older unused template images are retained.

## Deploy

Keep the existing Vercel Git integration and static site settings. Push changes to its configured production branch to trigger a deployment. This repository requires no framework or dependency installation.
